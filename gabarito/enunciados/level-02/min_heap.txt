Implement a class named `MinHeap` that implements a binary minimum heap stored within a Python list.

The class must provide the following methods:

1. `__init__(self)`:
Initializes an empty binary min-heap.

2. `push(self, val: int) -> None`:
Inserts `val` into the heap in $O(\log n)$ time complexity (sift up).

3. `pop(self) -> int | None`:
Removes and returns the minimum value from the heap in $O(\log n)$ time complexity (sift down). Returns `None` if the heap is empty.

4. `peek(self) -> int | None`:
Returns the minimum value without removing it in $O(1)$ time complexity. Returns `None` if the heap is empty.

5. `size(self) -> int`:
Returns the total number of elements currently stored in the heap in $O(1)$ time complexity.

You may not use the built-in `heapq` module.

Examples:

h = MinHeap(); h.push(5); h.push(3); h.push(8); h.peek()
Expected: 3

h = MinHeap(); h.push(5); h.push(3); h.push(8); h.pop()
Expected: 3

h = MinHeap(); h.push(5); h.push(3); h.push(8); h.pop(); h.peek()
Expected: 5

h = MinHeap(); h.push(5); h.push(3); h.push(8); h.size()
Expected: 3

h = MinHeap(); h.pop()
Expected: None

Forbidden: heapq
